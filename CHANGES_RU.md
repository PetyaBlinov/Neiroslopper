- Кнопки и переключатели способов связи получили сглаженные скругления. Текст остаётся нативным; управление мышью/клавиатурой и блокировки ttk сохранены. Светлее сделаны обычные и недоступные подписи.
- Добавлен режим Bluetooth Classic SPP: выбор сопряжённого исходящего COM-порта, обновление списка, честные метки неопределённых портов, без автоподключения или сопряжения. Нужна BT-прошивка; фактическая запись BT1/связь с платой ещё не выполнены. USB/Wi-Fi/Демо сохранены.
- Подъём ручки на время хода включён по умолчанию по просьбе пользователя. Без связи или подтверждённого реле движение не включается; сам запуск приложения не отправляет команд.

- 220 автоматических тестов прошли. Добавлены 11 проверок DPI, 9 Bluetooth и регрессия повторной перерисовки. Проверены настоящие окна Windows и геометрия при масштабе 200%; физическое оборудование не использовалось.

# Исправления ручного запуска — 03.11.2026

- Для нового MKS-профиля убрана лишняя перестановка осей Arduino: горизонтальные стрелки управляют логической X (каретка), вертикальные — Y (портал). Выбранные направления сохраняются при переключении профилей и переподключении.
- Ранний Idle после принятия jog больше не считается завершением: ожидается расчётная конечная точка. Повреждённый ответ координат вызывает остановку и отключение связи, а не считается ошибкой ввода формы.
- В ограниченном режиме срок одного включения соленоида контролируется и при ожидании ответов; повторный M8 не продлевает его. После разрыва связи кнопки обновляются до показа окна ошибки. Сообщение ALARM:3 уточнено.

# Новая разводка Neiroslopper — 02.11.2026

- В настройках добавлены явная подпись физических разъёмов X+Z/Y1, кнопка «Проверить концевики» и свежие статусы X/Y. Она отправляет только запрос состояния `?`, без движения или переключения реле. Запуск `$H` из приложения не добавлен; описанный в YAML поиск выполняется отдельно через штатные средства платы.
- Проверка: 103 автоматических теста прошли; реальные COM-порт, двигатели и реле в этих тестах не используются.

- Добавлен профиль проекта YAML под монтажную схему с тремя драйверами: логическая X (каретка ручки) на физическом Y1, логическая Y (портал) на физических X и Z. Y2 свободен; отдельной шаговой оси Z нет.
- Управление реле предусмотрено через LASER/TTL S, ожидаемый GPIO32, назначенный только `coolant.flood_pin`. M8/M9 дают дискретные состояния без Laser/PWM. Полярность остаётся неподтверждённой до проверки реального модуля с выключенным БП соленоида.
- В новой схеме предусмотрены два NC-концевика каретки/портала на физических LIMIT X/Y (ожидаемые GPIO36/35). Питание на механические выключатели не подаётся; используются S→NC и G→COM. Один датчик портала не является автоматическим выравниванием его сторон.
- Документация теперь содержит назначение цветов реле, моторных жил и предложенных проводов концевиков, два отдельных БП и защитный диод соленоида. Старые иллюстрации с SCL/GPIO4 помечены как прежний вариант.
- Мастер по-прежнему экспортирует файл офлайн: ничего не прошивает и не загружает. Численные параметры механики, соответствие GPIO ревизии v2.2, направления и полярность требуют проверки. Обновление программы не является отчётом о выполненном монтаже или физическом рисовании.

# Что изменено при переносе

- Создана отдельная копия программы; 64 исходных файла товарища сохраняются без изменений.
- Убраны обязательные JD_Plotter_DLC32_V2, плата V2.0_001, DWIN/TCP8888, фиксированный GPIO4 и предположение о наличии двух NC-концевиков.
- Рабочий профиль определяется фактическим YAML, с проверкой физической XY/I2S-конфигурации, численных параметров, конфликтов GPIO и стартовых макросов. Тестовая конфигурация подключается для диагностики, не разрешая движение.
- USB для MKS открывается с DTR/RTS=False до открытия. Диагностическое подключение/отключение и закрытие окна не посылают сброс, команды движения, реле или запись настроек. Явный СТОП по-прежнему отправляет программный сброс.
- Профиль реле читается из coolant/flood_pin, поддерживается реальная активная LOW/HIGH полярность. Не приписывается несуществующий аппаратный watchdog. По умолчанию полярность неизвестна и непрерывное питание отключено.
- Сохраняются ожидание подтверждений, проверка Idle, работа с MPos/WCO/G54, запрет повторов после ошибки связи, редактор и геометрия рисунков.
- Перезапуск FluidNC, а не только Grbl, инвалидирует сеанс и калибровку.
- Новый интерфейс с зелёным акцентом, вкладками управления и настроек, заметным STOP, офлайн-эскизом A4. Добавлен мастер экспорта YAML без загрузки в плату.
- Зависимости и запуск подготовлены локально; исходные чужие настройки и пароли не переносились. После подключения пользователя реальная MKS успешно опрошена новым кодом на COM5 только чтением версии, YAML и состояния; исполнительные устройства и рабочий YAML не подключались и не настраивались.

## Neiroslopper

Подключён предоставленный пользователем логотип: точный PNG и Windows ICO с несколькими размерами. Иконка используется основным окном и дочерними окнами; задана идентификация процесса для панели задач Windows. Добавлены GitHub README, документация, шаблоны issues/PR и автоматические Windows-тесты. Локальные данные и окружение исключены из Git.

Windows-иконка дополнительно назначается реальному внешнему окну через WM_SETICON после его создания. Для запуска создан локальный ярлык Neiroslopper с собственной ICO-иконкой; INSTALL.cmd создаёт такой же ярлык после установки.
