# Работа над Neiroslopper

Основная программа — Windows/Tk-приложение для официальной FluidNC. Изменение рисунка, отправка задания и прошивка контроллера остаются разными действиями.

## Ветки

| Ветка | Для чего |
| --- | --- |
| `main` | Проверенная версия, которую можно запускать |
| `develop` | Сборка следующего набора изменений |
| `feature/короткая-тема` | Новая возможность |
| `fix/короткая-тема` | Исправление ошибки |

Для названий рабочих веток удобнее латиница: `feature/svg-import`, `fix/serial-timeout`.

Обычный цикл:

```powershell
git switch develop
git pull --ff-only
git switch -c feature/my-change
```

Сделайте одну законченную правку, выполните проверки и откройте pull request в `develop`. После проверки подготовленный набор изменений переносится из `develop` в `main`. Постоянные ветки `main` и `develop` не переписываются через force push.

## Подготовка окружения

Установите Python3.11–3.14 x64 с Tcl/Tk. Запустите INSTALL.cmd, затем START.cmd. Окружение `.venv` создаётся локально и не коммитится.

Базовые зависимости — в requirements.txt; дополнительные камера/обводка — в requirements-camera.txt.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Для проверки окна используйте DEMO: подключение, шаг, два угла, рисунок, СТОП. Не используйте физический станок как замену регрессиям.

В описании PR достаточно указать:

- что меняется для пользователя;
- как это проверено;
- какие реальные устройства проверялись, если проверялись;
- требуется ли изменение YAML или проводки.

## Соглашения о поведении

- Подключение к штатной FluidNC читает её данные; оно не должно само двигать оси, включать реле, разблокировать Alarm или менять конфигурацию.
- Default/Test Drive без I/O остаётся доступным для диагностики, но не считается рабочим аппаратным профилем.
- После ошибки транспорта команды движения не повторяются автоматически, задание не продолжается после переподключения.
- Готовность определяется фактическим YAML и координатами, а не строкой имени платы.
- M8/M9 обозначают питание катушки. Логическое «ручка вверх/вниз» и электрическая LOW/HIGH полярность проверяются отдельно.
- Штатная FluidNC не содержит JD-DGUS/lease-сервис из прежней специальной прошивки. Не добавляйте зависимость от него в обычный USB/TCP путь.

## Что не коммитить

`.venv`, runtime-папку data, пароли и токены, реальные диагностические журналы, резервные копии flash и пользовательские автосохранения. Для регрессий используйте небольшие обезличенные примеры.

Для чужих изображений, шрифтов и фрагментов кода сохраните сведения об источнике и условиях использования. Общая лицензия проекта пока не выбрана; не добавляйте чужому коду произвольную лицензию.
