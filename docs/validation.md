# Что проверено

Neiroslopper **0.2.0**, 05.11.2026: **193 автоматических теста прошли**. Используются имитаторы, скрытые окна Tk и TCP только на localhost; порт физического станка тесты не открывают.

## Автоматические проверки

| Группа | Содержание |
| --- | --- |
| Сеанс | Идентификация FluidNC, канонический YAML, no-I/O-диагностика, готовность |
| Моторы | G21/G91, преобразование осей, одна команда на ручной ход, ранний Idle до старта Jog, ожидаемая конечная точка |
| Подъём | Полярность, M8/M9, выключение после остановки, срок 10 с для MKS и прежний 1,65 с для Uno |
| Ошибки | Повреждённые координаты, неполная запись, отсутствие повторов, STOP, гонки и перезапуск ESP32 |
| Wi-Fi | Поиск и проверка FluidNC, отмена, поздние результаты, выбор из нескольких плат и сохранённые подсказки; без настоящей LAN |
| Транспорт | USB без перенастройки DTR/RTS во время движения, фрагменты TCP, EOF, частичная отправка и тайм-аут |
| Окно | USB/Wi-Fi/Демо, один job на нажатие, блокировка занятых элементов, обновление кнопок до диалога ошибки |
| Редактор и Демо | SVG, кириллица, история, офлайн-эскиз, два угла; MKS в Демо использует режим 10 с |
| YAML | Числа, макросы запуска, STEP/DIR, два мотора портала, конфликтующие GPIO и концевики |

Для MKS проверен ход 10 мм при 80 шагах/мм, F150 и ускорении 10: расчётное движение около 4,25 с выполняется одной командой. Проверены переходы подряд без обязательного охлаждения 2,2 с, цельный G1, отказ слишком длинного хода до M8 и отсутствие продления срока повторным M8.

Запуск на Windows с Python3.11–3.14 и Tkinter:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## Настоящая установка

По USB считаны **v4.1.1-JD-DGUS1**, конфигурация, Idle и сеть FluidNC/AP 192.168.0.1/Telnet 23. Обнаружен DWIN-мост UART 23/33. Реле и подъём проверялись физическими импульсами M8/M9. После восстановления провода пользователь подтвердил работу соленоида.

05.11 загружен `neiroslopper_portal_fixed.yaml`. Сохранена резервная копия; после перезапуска прочитаны выбранный файл и полный YAML. Подтверждены изменение только второго портального DIR на `i2so.4:low`, сохранение JD/DWIN, реле и остальных параметров, состояние Idle. Движений при загрузке не было.

## Пределы результата

Физическое движение после инверсии Z ещё не проверено. Не подтверждены калибровка 80 шагов/мм, токи, ход 1000 мм, длительный режим катушки, настоящее Wi-Fi-подключение и рисунок на MKS. Расчётные координаты не измеряют вращение моторов.

Причина первого ALARM:3 не объявлена полностью установленной: прежний журнал содержал Abort Cycle до сброса приложения. Наблюдение встречной работы моторов объясняет инверсию Z, но не доказывает единую причину всех прежних USB-ошибок.

Реальные журналы, абсолютные пути компьютера, пароли и резервные копии прошивки остаются локально. Исходный пульт команды сохраняется отдельно без правок; версия 0.2.0 публикует рабочую адаптацию и тесты.
