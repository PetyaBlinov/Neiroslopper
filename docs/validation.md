# Что проверено

Базовая проверка программного переноса на 01.11.2026: **70 тестов прошли**,45Python-файлов компилировались. Исходные64файла предоставленного пульта были сверены по SHA-256 и остались неизменными. Рабочая версия создавалась отдельной копией.

## Автоматические проверки

| Группа | Содержание |
| --- | --- |
| Сеанс контроллера | Штатная идентификация FluidNC, YAML, диагностическое no-I/O-подключение, запрет движения до готовности |
| Исполнительные команды | Реальная полярность выхода, M8/M9, последовательность подъёма и опускания |
| Ошибки и отмена | Неполная запись, отсутствие повторов, STOP, гонка отмены и записи, перезапуск ESP32 |
| Координаты | MPos/WCO, сохранение смещения, G54 и неоднозначные ответы |
| Конфигурация | Дубликаты YAML, aliases, макросы запуска, численные диапазоны, STEP/DIR, конфликтующие GPIO |
| Транспорт | Открытие USB без DTR/RTS, фрагменты TCP, EOF, частичная отправка и тайм-аут |
| Окно и редактор | Начальное DEMO, неподтверждённая полярность, выключенное непрерывное питание, офлайн-эскиз, кириллица |
| DEMO | Подключение → перемещение → два угла → тестовый рисунок → STOP с сохранением эскиза |

Протокольные тесты используют подменённый контроллер. Сокетные проверки обращаются только к localhost. Они не открывают порт физического станка.

Запуск на Windows:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Для тестов окна нужен Tkinter и доступная графическая сессия Windows.

## Реальная плата

Новый sender успешно выполнил чтение штатной FluidNC через USB. Отправлялись только `$I`, `$Config/Dump` и запрос состояния `?`. Получены Idle и Default(Test Drive no I/O).

При этой проверке не выполнялись reset, движение, управление реле, разблокировка, прошивка или загрузка конфигурации. Поэтому результат подтверждает совместимость диагностического протокола, но не физическое рисование и не новую проводку.

## Что не считается испытанным

Реальные направления, шаги/мм, токи драйверов, границы хода, реле, нагрев катушки, длительная Wi-Fi-работа и рисунок на MKS ещё требуют проверки. Камера, сканер и DWIN в текущую аппаратную проверку не входили.

Реальные машинные журналы, абсолютные пути компьютера и резервные копии прошивки остаются локально и не публикуются в репозитории. Изменение числа тестов после этой базовой проверки следует отражать в README и этой заметке по фактическому результату прогона.
