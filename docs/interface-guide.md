# Neiroslopper — инструкция по интерфейсу

Инструкция **0.6.0**, обновлено **09.11.2026**. Главное окно оформлено в тёмно-синих тонах с золотыми дорожками, светлым текстом и скруглёнными кнопками. Масштабирование Windows учитывается при запуске, чтобы окно не растягивалось как готовая картинка. Старые снимки с зелёной темой и номерами этапов относятся к прежнему интерфейсу.

## Подключение сверху

Выберите **USB**, **Wi-Fi**, **Bluetooth** или **Демо**, затем нажмите **«Подключить»**. В USB доступно **«Обновить порты»**. В Wi-Fi нажмите **«Найти плату»**, выберите проверенное устройство и подключитесь. IP-адрес вводить не требуется. Для Bluetooth сначала выполните сопряжение в Windows, затем обновите список и выберите исходящий COM-порт платы. На MKS должна быть установлена BT-прошивка; подготовленный BT1 пока не записан и реальная связь не испытана. Профиль платы находится слева в **«Настройках»**.

## Слева — тестирование и настройки

| Элемент | Что делает |
| --- | --- |
| Стрелки | Один клик выполняет один ход на выбранное расстояние. |
| «Шаг, мм» / «Скорость, %» | Расстояние одного хода и доля максимальной подачи осей. |
| «Поднимать ручку на время хода» | Включает подъём при стрелках. По умолчанию включено. Если выключить — ручку нужно поднять или вынуть вручную. Сам запуск программы не поднимает ручку. |
| «Проверить подъём и возврат» | Краткий тест ручки без движения осей, с выключением питания по окончании. |
| «Показать квадрат 10 мм» | Загружает тестовый квадрат в предпросмотр. Само по себе не двигает станок. |
| Вкладка «Настройки» | Профиль и мастер платы, проверка конфигурации/концевиков, направления, реле, отступ SVG, камера и DWIN. Панель прокручивается. |

## Справа — бумага, рисунок и запуск

| Элемент | Что делает |
| --- | --- |
| «Задать верхний левый угол» | Сохраняет текущее положение головки как начало листа. Сначала подведите её туда стрелками. |
| «Задать нижний правый угол» | Сохраняет вторую точку и определяет размеры области. Подведите головку вправо и вниз от первого угла. |
| «Сбросить» | Удаляет калибровку листа, сохраняя рисунок. Движения не запускает. |
| «Редактор» | Открывает редактор текста, фигур и проектов. Работает без платы. |
| «Помощник» | Открывает диалог для подготовки и изменения эскиза. В нём «Голос» → запись → распознавание → проверка → вставка в запрос. Предложение показывается до отдельного применения. [Инструкция](assistant-guide.md). |
| «Открыть SVG…» | Загружает векторный рисунок. Отступ задаётся слева: «Настройки» → «Рисунок». |
| Предпросмотр | Белый лист, синие штрихи рисунка и оранжевые переходы с поднятым пером. |
| «Подвести к началу» | Перемещает головку к началу выбранного рисунка. |
| «Начать рисование» | После подтверждения запускает подготовленную траекторию. Доступно после подключения, проверки настроек, обоих углов и выбора рисунка. |
| Короткий статус рядом с запуском | Показывает, какое условие ещё не выполнено или что приложение готово к работе. |

Эскиз A4 доступен сразу, но не заменяет два угла на реальной бумаге. Углы нужно задавать заново после STOP или разрыва связи.

## Справка, журнал и остановка

**«Справка»** вверху содержит краткое руководство и вкладку текущего состояния: подключение, разводку осей, параметры ручки и подробные сообщения. **«Журнал»** внизу разворачивает технические записи; изначально он скрыт. Эти окна не отправляют команды станку.

**СТОП · Esc** остаётся видимым и отправляет программный сброс. Рисунок сохраняется, углы сбрасываются. При потере связи отключайте силовое питание вручную.

## Параметры ручки

В **«Настройках» → «Ручка и соленоид» → «Параметры реле…»** сохранены прежние возможности: HIGH/LOW, действие питания, подтверждение физической проверки, ограничение времени, задержки подъёма/опускания, сохранение и короткий импульс. Изменение оформления не меняет GPIO, YAML и поведение движения.

Для MKS режим по умолчанию ограничивает одно включение катушки 10 секундами, для прежней Uno сохраняется её ограниченный режим. Программа не измеряет температуру катушки. Подробности выбранного режима доступны в справке.

## Окно «Редактор»

Редактор меняет только эскиз. Движение запускается отдельно в главном окне.

| Элемент | Назначение |
| --- | --- |
| «Открыть проект» / «Сохранить проект» | Загружает или сохраняет редактируемый проект с листом и объектами. |
| «Сохранить SVG» | Экспортирует подготовленные линии в SVG. |
| «Отменить» / «Повторить» | Отменяет или возвращает применённые правки эскиза. |
| «Рисунок по образцу» | Открывает загрузку PNG/JPG/SVG, поиск образца и построение обводки. Полученную обводку нужно отдельно применить к эскизу. |
| «Текст» | Ввод надписи на русском и латинице однолинейным печатным шрифтом. Настраиваются высота букв, интервал, размер блока и размещение. |
| «Предпросмотр надписи» | Создаёт предварительную версию надписи. Затем нажмите «Применить к эскизу». |
| «Заменить текст выбранного объекта» | Меняет содержание выбранного текстового объекта с предпросмотром. |
| «Добавить объект, сохранить остальные» | Сохраняет остальные объекты при создании новой надписи. Если снять, новая надпись заменит композицию в предпросмотре. |
| «Правки» | Масштаб, поворот, сдвиг вправо/вниз, ширина, центрирование, отражение, удаление объекта и сокращение переходов. Числа задаются в мм, градусах или процентах по подписи поля. |
| «Фигуры» | Прямоугольник, эллипс, треугольник, линейка или тест точности с заданными размерами. «Добавить фигуру» сначала создаёт предпросмотр. |
| «Проект» | Пробный лист, шаблоны и восстановление автокопии. Пробный лист задаёт размер эскиза, а не ноль станка. |
| Выбор объекта над рисунком | Выбирает отдельный объект или всю композицию для правок. Также можно нажать на линии объекта. |
| «Применить к эскизу» | Принимает предпросмотр и передаёт результат в главное окно. Моторы не запускает. |
| «Отменить предпросмотр» | Отбрасывает только ещё не применённую правку. |

## Окно «Настроить плату…»

Для профиля Neiroslopper задаются логическая X (каретка на Y1) и логическая Y (портал на X+Z). У зеркального второго мотора текущей установки DIR — `i2so.4:low`. Заполните измеренные шаги/мм, подачу, ускорение и ход; GPIO и полярность реле сверяются с проводкой. [Пример текущей раскладки](../EXAMPLES/neiroslopper_mks_dlc32_v22.yaml) помечен как некалиброванный.

«Предпросмотр YAML» показывает проект файла; «Экспорт проекта…» сохраняет его на диск; «Закрыть» закрывает окно. Экспорт не меняет прошивку и не загружает конфигурацию. Подтверждения отмечают выполненную сверку, а не запускают её. Этот мастер пока экспортирует только явно выбранный вариант без концевиков; наличие установленных концевиков нужно учесть отдельно.

## Проверка интерфейса без оборудования

1. Выберите профиль MKS и способ **Демо**, нажмите «Подключить».
2. Нажмите «Здесь верхний левый угол».
3. Выберите шаг 10 мм, нажмите → и ↓, затем «Здесь нижний правый угол». Получится пробная область 10 × 10 мм.
4. Нажмите «Тест 10 мм», проверьте квадрат на экране.
5. Нажмите «К началу рисунка» или «Начать рисование» и подтвердите DEMO. Реальная плата при этом не используется.
6. Нажмите «СТОП / ESC». Эскиз останется, углы потребуется задать заново.

Для редактирования подключение даже к DEMO не нужно: нажмите «Редактор» и используйте пробный лист A4.

## Продолжение физической проверки

1. На MKS загружен `neiroslopper_portal_fixed.yaml`; read-back и Idle подтверждены. После исправления направления Z физическое движение ещё не проверено. Сначала сверить проводку и параметры драйверов.
2. Выбрать MKS и **USB → COM-порт** либо **Wi-Fi → Найти плату**. Порт не должен быть открыт другой программой.
3. Проверить коротким ходом синхронность зеркальных сторон портала, независимую каретку и подъём ручки. Соленоид уже заработал после восстановления провода; длительный режим ещё не проверен.
4. Закрепить лист параллельно осям и задать его два угла. Пробный A4 в редакторе эту операцию не заменяет.
5. Выполнить короткий тест сначала без ручки, затем с ручкой. Проверить масштаб и прижим.

Если кнопка серая, приложение ждёт нужное состояние: связь, рабочую конфигурацию, подтверждённую ручку, оба угла или окончание текущей операции. Короткий статус у запуска показывает причину блокировки; подробности доступны в «Справке» и раскрываемом «Журнале».

## Чёткость и масштаб

Оформление выбирает Segoe UI Variable Text, если он установлен, иначе Segoe UI. Текст остаётся нативным текстом, а не изображением. Скругления кнопок сглаживаются отдельно. DPI учитывается до создания окна; размеры и отступы увеличиваются вместе со шрифтами. Системные настройки сглаживания и масштаба не меняются. При переносе между мониторами с разным DPI для корректного масштаба может потребоваться перезапуск приложения.

Технические основы: [DPI Windows](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setprocessdpiawarenesscontext), [элементы изображений ttk](https://www.tcl-lang.org/man/tcl8.6/TkCmd/ttk_image.htm), [Bluetooth SPP и Windows](https://learn.microsoft.com/en-us/windows/uwp/devices-sensors/bluetooth-dev-faq).
