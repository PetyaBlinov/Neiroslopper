Для такой архитектуры все три устройства могут находиться в одной локальной сети роутера. Ноутбук отдельно отправляет команды MKS и получает изображение камеры. Прямого обмена MKS↔камера в опубликованном коде не найдено, и для описанного пути через ноутбук он не требуется.

## Чего в репозитории не хватает

- Прошивки/скетча самой ESP-камеры и способа задать ей сеть роутера.
- Общего мастера, который подключает MKS и камеру к одному SSID.
- Автопоиска камеры: её URL вводится вручную.
- Подтверждения текущих версий прошивок и физической проверки всей установки. Отчёт сборки MKS содержит `hardware_tested: false`.

Поэтому утверждение «все три устройства работают в одной сети» совместимо с опубликованной архитектурой, если устройства уже настроены снаружи. Новый законченный комплект настройки этого подключения на GitHub не найден.

У товарища следует запросить **прошивку камеры, инструкцию подключения к общему роутеру и версии прошивок, реально установленных на MKS и камере**. Реальные пароли Wi-Fi и личные настройки в открытый репозиторий добавлять не требуется: достаточно примера конфигурации.

## Наша текущая версия

В Neiroslopper0.7.0 оставлены **USB, Wi-Fi и Демо**. Для Wi-Fi ноутбук и MKS должны быть доступны в одной сети; поиск MKS запускается кнопкой «Найти плату». Камера подключается отдельно по своему HTTP-адресу. Программа не меняет сетевые настройки устройств автоматически.

Подготовка экспериментального Bluetooth-варианта отменена пользователем. Кандидаты и инструкции его установки убраны из актуальных локальных файлов. По журналам BT1 никогда не записывалась: последнее сохранённое чтение от06.11 показывало `v4.1.1-JD-DGUS1` и точку доступа FluidNC. Перепрошивка для отмены этой подготовки не выполнялась и по имеющимся данным не нужна; сегодняшнее состояние физической платы здесь не проверялось.
