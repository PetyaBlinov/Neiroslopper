# Прошивка FluidNC для MKS DLC32 V2.2

Эта сборка основана на [FluidNC v4.1.1](https://github.com/bdring/FluidNC/tree/fdc17a2c9c0367b07345c16da3937ff0739d4702) и добавляет JD-DGUS 2.1. Двоичный файл `firmware-v4.1.1-JD-DGUS2.1.bin` и соответствующие исходники `fluidnc-jd-dgus-source.zip` распространяются вместе. Лицензия FluidNC включена в `COPYING-FluidNC.txt`.

Для сборки распакуйте исходники в отдельную папку, установите PlatformIO Core и выполните `pio run -e wifi` из папки с `platformio.ini`. Бинарный результат — `.pio/build/wifi/firmware.bin`.

Для нового меню помощника и предпросмотра нужны оба обновления: прошивка MKS и пакет интерфейса DWIN. Сверьте маркировку MKS DLC32 **V2.2**, модель дисплея, конфигурацию и сохраните резервную копию платы перед обновлением. Файл `.bin` — образ приложения для адреса `0x10000` на проверенной схеме разделов. Применяйте его только после проверки схемы разделов на своей плате. Настройки Wi-Fi в комплекте отсутствуют.

`jd_v22_dwin9600.yaml` — пример конфигурации, зависящий от разводки. Сверьте UART, оси и реле со своим оборудованием.
