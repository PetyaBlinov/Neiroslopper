# Пульт плоттера с помощником DWIN

Этот вариант лежит в отдельной папке и устанавливается отдельно от основного Neiroslopper. Программа запускается в DEMO. Для запуска и тестов подключать плоттер не требуется.

## Установка на Windows

1. Установите Python 3.11 или новее с компонентом Tcl/Tk.
2. Запустите `INSTALL.cmd`, затем `START.cmd`.
3. Для свободных ответов установите Codex CLI и войдите через ChatGPT командой `codex login`. Пульт использует этот вход.
4. Для кнопки «Голос» запустите `PROGRAM/INSTALL_VOICE.cmd`. Установщик загрузит локальные модели распознавания. Кнопка включает системный микрофон ПК, повторное нажатие завершает запись. В Codex передаётся распознанный текст.
5. Для камеры, поиска образцов и просмотра обводок установите зависимости через `PROGRAM/INSTALL_CAMERA.cmd`.

## DWIN и MKS DLC32 V2.2

Для нового меню обновите [интерфейс DWIN](display/DWIN_ASSISTANT_800x480_20261108.zip) и [прошивку MKS](firmware/firmware-v4.1.1-JD-DGUS2.1.bin). Подключите ПК к проверенной MKS через Wi-Fi по адресу платы на порту 23. При опознании JD-DGUS пульт откроет канал экрана на порту 8888. IP-адрес своей платы укажите в пульте.

- «Помощник» принимает короткие вопросы с клавиатуры экрана или голос с микрофона ПК. Экран показывает состояние запроса и короткий ответ. Вопросы не запускают движения и не применяют изменения к эскизу.
- «Лист» показывает загруженную композицию с сохранением пропорций. Очень мелкие детали могут исчезать при уменьшении для DWIN. Если автоподъём выключен, соединения между штрихами входят в картинку. Кнопка «Обновить» запрашивает текущий лист. Это схема рисунка.
- Для физического рисования используйте отдельную команду пульта после установки двух углов листа.

`firmware/jd_v22_dwin9600.yaml` — пример конфигурации для проверенной ревизии платы и её разводки. Сверьте оси, драйверы, реле и дисплей на своём станке перед применением. Источник и инструкция сборки FluidNC приведены в [firmware/README.md](firmware/README.md).

Видео с камеры открывается отдельно на ПК.
