# MKS DLC32 V2.2 и DWIN

Канал панели работает по JD-DGUS поверх TCP 8888, канал FluidNC — по TCP 23. Дисплей работает через UART1 MKS с настройкой 9600 бод. Модель экрана и разводку необходимо сверить на конкретном оборудовании.

Пульт начинает работу в DEMO. Чтобы подключиться по сети, выберите MKS DLC32 V2.2 и введите tcp://адрес-платы:23. При подключении совместимой прошивки программа определяет канал DWIN. Лист задаётся двумя углами. Стрелки и физический запуск доступны только при подходящей проверенной конфигурации. Голос распознаётся на ПК и передаётся Codex как текст.
