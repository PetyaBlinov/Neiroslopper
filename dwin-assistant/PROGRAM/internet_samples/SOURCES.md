# Интернет-образцы рукописного текста

Готовые файлы для нашей программы:

- `ems_allure_cheer_3mm.svg` — cheer, номинальная высота основной части строчных 3 мм.
- `ems_allure_cheer_2mm.svg` — cheer, 2 мм.
- `ems_allure_elle_3mm.svg` — elle, 3 мм.

Слова собраны локально из скачанного штрихового SVG-шрифта EMS Allure. Это подготовленные образцы на основе интернет-шрифта, а не неизменённые готовые рисунки автора. Между буквами добавлены короткие соединения; у всех выбранных букв один штрих, поэтому каждый итоговый файл содержит одну непрерывную полилинию без подъёма пера. Размер сохраняется 1:1 в обновлённой программе. Верхние петли выходят за номинальную высоту строчных. Поддержка кириллицы в этом скачанном шрифте не обнаружена; данные образцы латиницей.

Автор EMS Allure: Sheldon B. Michaels. Преобразование в SVG: Windell H. Oskay. Производный от Allura: Rob Leuschke, TypeSETit. Лицензия шрифта по встроенным сведениям: SIL Open Font License; сведения сохранены в исходном SVG и в метаданных образцов.

Исходный файл: https://gitlab.com/oskay/hershey-text/-/raw/Inkscape_v1/hershey-text/svg_fonts/EMSAllure.svg

Документация проекта: https://wiki.evilmadscientist.com/Hershey_Text

Дополнительные найденные инструменты:

- Plotter Text: https://drawingbots.com/tools/plotter-text/ — создание надписей штриховыми шрифтами и экспорт SVG.
- Mistral SingleLine: https://github.com/isdat-type/Mistral-SingleLine — открытый рукописный штриховой шрифт; требуется подготовка контуров и проверка подъёмов пера.
- VHS: https://github.com/utrost/VHS — сборка SVG из собственных записанных рукописных букв.

Штриховой шрифт не гарантирует одну непрерывную линию на слово: отдельные штрихи, точки и перекладины могут требовать подъёма пера. Для плоттера без подъёма проверяйте оранжевые переходы.
