# DWIN 800 × 480 с помощником и просмотром листа

Пакет для MKS DLC32 V2.2 с поддержкой запроса помощника и предпросмотра листа. Он сохраняет ранее установленные страницы движения, разметки, рисования и проверки связи с ПК.

- **Помощник** открывает клавиатуру. Кнопка EN/RU переключает раскладку. Вопрос ограничен 120 символами.
- **Голос** запускает запись с выбранного в программе микрофона компьютера. Нажмите **Голос / стоп**, чтобы закончить запись.
- После отправки появляются статус передачи, ожидание и короткий ответ. Полный ответ доступен в программе на компьютере.
- **Предпросмотр** показывает текущий рисунок на листе. Компьютер передаёт упрощённую картинку для экрана. Для обновления используйте **Обновить лист**.
- **СТОП** доступен на каждой рабочей странице.

Для установки нужны новый пакет экрана, совместимая прошивка MKS и обновлённая программа на ПК. Папка `DWIN_SET` содержит файлы интерфейса и кириллический шрифт. Настройки связи и ядро экрана этот пакет не перезаписывает. Загружайте `DWIN_SET` с подготовленной карты при отключённом питании дисплея.

Откройте `preview.html`, чтобы попробовать кнопки в браузере. В этой демонстрации используются образцы ответа и рисунка. Файлы проверены программно. Установка и работа на физической панели не проверялись.

Описания контролов и разметки VP приведены в [руководстве DWIN T5L DGUS II](https://forums.dwin-global.com/wp-content/uploads/2023/06/T5L_DGUSII-Application-Development-Guide-2022331-1.pdf), разделы 7.13 и 7.22.
