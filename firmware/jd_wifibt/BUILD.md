# Экспериментальная Wi-Fi + Bluetooth + DWIN

Кандидат `v4.1.1-JD-DGUS1-BT1` основан на пользовательском JD-DGUS1 и FluidNC4.1.1.
Сохраняет Wi-Fi и TCP8888↔UART23/33 для DWIN, добавляет Classic Bluetooth SPP.
Исходники обработки движения, назначение выводов и протокол DWIN не изменены.

Это отдельная проверочная сборка. Её наличие не подтверждает работу на плате.
Текущая прошивка пользователя и YAML не входят в пакет и не заменяются сборкой.

## Сборка

Требуются Python3.12, Git, PlatformIO6.2.0 и доступ к официальному реестру.

```sh
python -m pip install platformio==6.2.0
python firmware/jd_wifibt/build.py
```

Скрипт проверяет SHA256 исходников, распаковывает изолированную копию и собирает
`jd_wifibt`. Результаты находятся в `firmware/jd_wifibt/output/`.
Проверяются размер, заголовок8MB, наличие BT/DWIN и сохранность экранного модуля.
Все версии зависимостей закреплены; Git-репозиторий пользователя не исследуется
генератором номера версии. Исходники распространяются под GPL-3.0-or-later
с сохранением отдельных лицензий файлов; см. LICENSE и AUTHORS внутри source.zip.

## Перед установкой

Пакет не содержит автоматического прошивальщика. Таблица разделов — только
кандидат для8MB: два3MBслота и прежний LittleFS `0x3D0000/0x30000`.
Перед записью нужны свежий полный резерв flash, проверка активного OTA-слота,
фактического bootloader/header и отдельная окончательная таблица под эту плату.
Не заливать buildfs или чужой комплектный config.yaml. Не стирать NVS/LittleFS.
При ошибочном разделе текущий LittleFS-монтаж может отформатировать раздел.

Первичная проверка после установки — USB/Bluetooth/Wi-Fi только запросами,
без движения/реле; затем экран и потеря связи. Обычный Bluetooth-канал не заменяет
сетевой канал DWIN: приложение должно сохранять Wi-Fi-связь с платой для экрана.
