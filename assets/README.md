# Логотип Neiroslopper

`icon.png` — точная копия изображения, предоставленного пользователем для иконки приложения и оформления проекта. Изображение не перерисовывалось.

`icon.ico` — Windows-контейнер того же изображения с размерами16,24,32,48,64,128 и256пикселей. Приложение использует ICO для Windows и PNG для Tk. Общая лицензия на этот графический материал отдельно не назначалась.
